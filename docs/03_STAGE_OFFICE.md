# 3단계 기획 및 구현 문서: Stage 1 Office

## 목표

사무실 탈출 구간을 완성한다. 실제 미로가 아니라, 3레인 러너 구조 안에서 파티션이 미로처럼 느껴지는 시야 연출과 상사/동료 압박을 와이어프레임으로 먼저 구현한다.

## 플레이어 경험

퇴근하려는 순간 사무실 통로가 길게 이어진다. 플레이어는 파티션 사이를 지나며 서류 더미를 뛰어넘고, 열린 캐비닛 문 아래로 슬라이드하며, 동료와 상사를 피해 엘리베이터로 향한다.

## 레벨 구조

- 목표 거리: 220m
- 참고 시간: 약 60초
- 레인: 기본 3레인 유지
- 폭: 현재 레인 폭 2.5 기준
- 배경: 좌우에 파티션과 책상을 반복 배치하되, 실제 이동 경로는 3레인 직선 구조를 유지
- 목표: 엘리베이터 앞 녹색 트리거 도달

## 와이어프레임 에셋

| 이름 | 형태 | 기능 |
| --- | --- | --- |
| `WF_OfficePartition` | 세로 큐브 | 시야 제한 벽 |
| `WF_DeskBlock` | 낮은 큐브 | 배경/충돌 없는 장식 |
| `WF_PaperPile_Ground` | 큐브 더미 | 점프 장애물 |
| `WF_CabinetDoor_Air` | 얇은 가로 큐브 | 슬라이드 장애물 |
| `WF_CoffeeSpill_Slow` | 얇은 원형/큐브 | 감속 구역 |
| `WF_Coworker_LaneBlock` | 캡슐 | 레인 차단 |
| `WF_BossChaser` | 큰 캡슐 | 추격 압박 연출 |
| `WF_ElevatorGoal` | 초록 박스 | 스테이지 종료 |

## 장애물 매핑

- 서류 더미: Ground 타입, 점프 회피
- 열린 캐비닛 문: Air 타입, 슬라이드 회피
- 질문하는 동료: LaneBlock 타입, 좌우 회피
- 믹스커피: SlowZone 타입, 접촉 시 속도 저하 또는 피로 증가
- 상사: 직접 충돌보다 뒤쪽 압박 UI/사운드로 먼저 구현

## 구현 작업

1. 사무실 테마 지면
   - 기존 `GroundTile`에 사무실 바닥 머티리얼을 임시 적용한다.
   - 타일 좌우에 파티션/책상 반복 배치 포인트를 둔다.

2. 장애물 프리팹
   - 기존 장애물 3종을 복제해 사무실 이름으로 변형한다.
   - 색과 크기로 회피 방식을 명확하게 구분한다.
   - 충돌 박스는 실제 보이는 큐브보다 약간 작게 둔다.

3. 스폰 테이블
   - 초반 20초: 서류 더미/동료 위주
   - 중반 20초: 캐비닛 문 추가
   - 후반 20초: 믹스커피와 연속 패턴 추가

4. 상사 압박
   - MVP에서는 실제 AI 추격보다 화면 뒤쪽의 거리 압박으로 처리한다.
   - 충돌이 잦으면 상사 경고 UI 또는 숨소리/발소리 볼륨을 올린다.

5. 엘리베이터 전환
   - `StageManager`가 220m 도달 시 `WF_ElevatorGoal`을 활성화한다.
   - `WF_ElevatorGoal`의 `StageExitTrigger`에 닿으면 Stage 2 로비 테마로 스폰 테이블과 배경을 교체한다.

## 완료 기준

- 플레이어가 사무실 분위기의 와이어프레임 구간을 끝까지 통과할 수 있다.
- 파티션은 시야를 제한하지만 회피 판단을 불공정하게 만들지 않는다.
- 장애물 회피 방식이 색과 형태만으로 구분된다.
- Stage 1 종료 후 Stage 2로 전환된다.

## 테스트 체크리스트

- 파티션이 카메라 시야를 과하게 가리지 않는가
- 장식 책상과 실제 충돌 장애물이 혼동되지 않는가
- 코너 연출이 있어도 반응 시간이 보장되는가
- 엘리베이터 목표 트리거가 한 번만 발동하는가
