# 4단계 기획 및 구현 문서: Stage 2 Lobby

## 목표

엘리베이터와 로비를 지나 건물 밖으로 나가는 두 번째 구간을 완성한다. 넓은 공간, 보안 게이트, 미끄러운 바닥을 중심으로 타이밍 싸움을 만든다.

## 플레이어 경험

엘리베이터 문이 열리고 로비로 나온다. 대리석 바닥은 미끄럽고, 보안 게이트와 경비원이 퇴근길을 늦춘다. 플레이어는 타이밍에 맞춰 열린 게이트 레인을 찾아 건물 밖으로 빠져나간다.

## 레벨 구조

- 목표 거리: 160m
- 참고 시간: 약 45초
- 레인: 3레인 유지, 일부 구간에서 중앙 레인을 강조
- 배경: 넓은 로비, 기둥, 인포메이션 데스크, 화분
- 목표: 건물 출구/자동문 트리거

## 와이어프레임 에셋

| 이름 | 형태 | 기능 |
| --- | --- | --- |
| `WF_ElevatorDoor` | 양쪽 큐브 문 | 시작 연출 |
| `WF_LobbyColumn` | 실린더 | 배경/시야 리듬 |
| `WF_InfoDesk` | 낮은 큐브 | 장식 |

| `WF_ExitDoorGoal` | 초록 박스 | 스테이지 종료 |

## 기획 보완

초기 아이디어의 엘리베이터 웨이브 방어와 사원증 리듬 게임은 매력적이지만 MVP에는 부담이 크다. 먼저 러너 규칙 안에서 다음처럼 단순화한다.

- 엘리베이터 대기는 3초 오프닝 연출로 처리한다.
- 사원증 태그는 별도 리듬 게임이 아니라 특정 레인을 통과해야 하는 게이트 패턴으로 구현한다.
- 후속 버전에서 짧은 QTE나 타이밍 입력으로 확장한다.

## 구현 작업

1. 시작 연출
   - Stage 2 진입 시 엘리베이터 문이 열리는 간단한 애니메이션을 만든다.
   - MVP에서는 플레이 상태를 유지하고, 문 애니메이션은 배경 연출로만 처리한다.
   - 자동 전진이나 입력 잠금은 후속 연출 단계에서 별도 컷신 상태로 추가한다.

2. 로비 배경
   - 타일 좌우 폭을 사무실보다 넓게 보이도록 장식물을 멀리 배치한다.
   - 바닥 머티리얼을 밝은 회색으로 둔다.

3. 게이트 패턴
   - 3개 레인 중 1개 또는 2개만 열린 패턴을 만든다.
   - 열린 레인은 초록/흰색으로, 닫힌 레인은 노랑/빨강으로 표시한다.

4. 미끄러운 바닥
   - `SlowZone` 구현이 있다면 피로 증가와 제어력 감소를 적용한다.
   - MVP에서는 단순 감속 또는 작은 넉백으로 대체한다.

5. 출구 전환
   - `StageManager`가 160m 도달 시 `WF_ExitDoorGoal`을 활성화한다.
   - `WF_ExitDoorGoal` 접촉 시 Stage 3로 전환한다.
   - 조명 색을 차가운 실내에서 비 오는 야외 톤으로 바꾼다.

## 완료 기준

- 엘리베이터 시작 연출 후 로비 플레이가 자연스럽게 이어진다.
- 게이트 패턴은 보고 피할 수 있다.
- 미끄러운 바닥의 효과가 과하지 않고 이해 가능하다.
- 출구 도달 시 Stage 3로 넘어간다.

## 테스트 체크리스트

- 게이트가 3레인을 동시에 막지 않는가
- 미끄러짐이 플레이어를 충돌 판정 밖으로 튕기지 않는가
- 엘리베이터 문이 플레이어를 끼우지 않는가
- 로비 장식물이 실제 장애물처럼 보이지 않는가
