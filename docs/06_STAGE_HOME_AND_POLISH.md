# 6단계 기획 및 구현 문서: Stage 4 Home & Polish

## 목표

집 도착 보상 구간, 엔딩, 결과 화면, 기본 사운드/연출을 완성한다. 이 단계가 끝나면 처음부터 끝까지 플레이 가능한 수직 슬라이스가 된다.

## 플레이어 경험

비 오는 길과 지하철을 지나 집 근처 골목에 도착한다. 음악과 조명이 따뜻해지고, 장애물은 거의 사라진다. 플레이어는 현관문을 지나 침대에 도착하고 하루를 마무리한다.

## 레벨 구조

- 목표 거리: 80m
- 참고 시간: 약 20-30초
- 속도: 이전 스테이지보다 낮춤
- 장애물: 거의 없음, 길 안내용 오브젝트 중심
- 목표: 침대 트리거

## 와이어프레임 에셋

| 이름 | 형태 | 기능 |
| --- | --- | --- |
| `WF_AlleyLamp` | 실린더+구 | 따뜻한 조명 포인트 |
| `WF_HomeDoorGoal` | 초록 문 박스 | 집 진입 |
| `WF_HallwayWall` | 긴 큐브 | 복도 |
| `WF_RoomFloor` | 넓은 큐브 | 방 바닥 |
| `WF_BedGoal` | 낮은 큐브 | 최종 클리어 트리거 |
| `WF_TV` | 얇은 큐브 | 보상 장식 |
| `WF_CanDrink` | 실린더 | 보상 장식 |

## 구현 작업

1. 속도와 난이도 완화
   - Stage 4 진입 시 스폰을 끄거나 안전한 장식만 스폰한다.
   - 플레이어 속도를 낮추고 카메라를 조금 가까이 둔다.

2. 집 도착 트리거
   - 골목 끝 `WF_HomeDoorGoal`에 닿으면 짧은 실내 구간으로 전환한다.
   - 초기에는 같은 씬 안에서 위치만 이어붙인다.

3. 최종 클리어
   - Foundation/Core Loop에서 준비한 `GameClear` 상태를 사용한다.
   - `StageManager`가 80m 도달 시 `WF_BedGoal`을 활성화한다.
   - `WF_BedGoal` 접촉 시 `GameManager`를 `GameClear`로 전환하고 결과 화면을 연다.

4. 결과 화면
   - 도착 여부
   - 귀가 시간
   - 이동 거리
   - 충돌 횟수
   - 남은 피로도
   - 다시하기/메인 메뉴 버튼

5. 사운드 1차 적용
   - 사무실: 타이핑/형광등
   - 로비: 구두 소리/엘리베이터 딩
   - 도심: 비/차량/지하철 안내
   - 집: 낮은 실내음/TV 소리

6. 연출 1차 적용
   - 스테이지별 조명 색 변경
   - 충돌 시 짧은 화면 흔들림
   - Stage 4 진입 시 UI 색 완화
   - 클리어 시 카메라가 침대 쪽을 바라보는 짧은 컷

## 품질 정리

### 코드

- Foundation/Core Loop에서 준비한 `GameClear` 상태 동작 확인
- 스테이지 전환 이벤트를 명확히 분리
- 장애물 효과가 플레이어 상태와 UI에 중복 반영되지 않게 정리
- 풀링 오브젝트가 스폰마다 이동/효과 상태를 초기화하는지 확인

### 레벨

- 모든 목표 트리거는 한 번만 실행되게 한다.
- 장식과 충돌 장애물은 색/레이어/이름으로 구분한다.
- 각 스테이지 시작 3초는 난이도를 낮춰 적응 시간을 준다.

### UI

- 모바일 화면에서 버튼과 텍스트가 겹치지 않게 한다.
- 게임 중에는 필요한 정보만 표시한다.
- 결과 화면은 플레이 재시작이 즉시 가능해야 한다.

## 완료 기준

- MainMenu에서 시작해 Stage 1-4를 거쳐 결과 화면까지 도달할 수 있다.
- 모든 스테이지는 와이어프레임 상태라도 테마와 장애물 규칙이 구분된다.
- 게임오버와 게임클리어가 모두 정상 동작한다.
- 재시작과 메인 메뉴 이동이 정상 동작한다.
- 플레이 중 치명적인 콘솔 오류가 없다.

## 최종 테스트 체크리스트

- 전체 플레이를 최소 3회 완주 테스트했는가
- 각 스테이지 전환이 한 번씩만 실행되는가
- 피로도/점수/거리 UI가 실제 상태와 일치하는가
- 게임오버 후 재시작이 정상인가
- 게임클리어 후 다시하기가 정상인가
- 와이어프레임 에셋 교체 위치가 명확한가
