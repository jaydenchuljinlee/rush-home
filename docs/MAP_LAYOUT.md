# 맵 와이어프레임 설계서

각 스테이지의 화면 구성을 정의한다. 플레이어가 달리면서 보는 화면이 어떤 오브젝트로 채워져야 하는지를 구체적으로 설계한다. 모든 오브젝트는 프리미티브(Cube, Cylinder, Sphere)와 단색 머티리얼로 구성한다.

---

## 현재 타일 구조 (기준)

```
단면도 (X축, 위에서 아래로 본 방향)

  Sidewalk_L   Curb  EdgeLine  LaneLine_L      LaneLine_R  EdgeLine  Curb  Sidewalk_R
  ┌──────────┐ ┃ ┃           ┊              ┊           ┃ ┃ ┌──────────┐
  │  3m wide │ ┃ ┃           ┊    도 로      ┊           ┃ ┃ │  3m wide │
  │  y=+0.2  │ ┃ ┃           ┊   8m wide    ┊           ┃ ┃ │  y=+0.2  │
  └──────────┘ ┃ ┃           ┊              ┊           ┃ ┃ └──────────┘
  x=-7    x=-4     x=-3.85  x=-2.5   x=0   x=+2.5  x=+3.85     x=+4    x=+7
```

| 파트 | X 범위 | Y 윗면 | 크기 | 머티리얼 |
|---|---|---|---|---|
| Road | -4 ~ +4 | 0 | 8 × 0.5 × 20 | M_Road (어두운 회색) |
| Sidewalk_L | -7 ~ -4 | +0.2 | 3 × 0.7 × 20 | M_Sidewalk (밝은 회색) |
| Sidewalk_R | +4 ~ +7 | +0.2 | 3 × 0.7 × 20 | M_Sidewalk |
| Curb_L/R | x=±4.1 | +0.2 | 0.2 × 0.3 × 20 | M_Curb |
| EdgeLine_L/R | x=±3.85 | +0.01 | 0.12 × 0.01 × 20 | M_LaneLine (흰색) |
| LaneLine_L/R | x=±2.5 | +0.01 | 0.12 × 0.01 × 2 (5개 반복) | M_LaneLine |

타일 길이: **20m (Z축)**, 활성 타일: **8장 (160m)**

**현재 문제**: 인도 바깥에 아무것도 없어서 허공에 떠 있는 도로처럼 보인다. 각 스테이지는 인도 위/바깥에 배경 오브젝트를 배치하여 공간감을 만들어야 한다.

---

## 공통 높이 기준 (Y축)

```
                    카메라 y=7
                        ↓

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  y=3.0  배경 최대 높이 (카메라 시야 보장)

  ┌──┐                                y=2.5  파티션/벽 상단
  │벽│  ┌───┐
  │  │  │책상│     ☻ 플레이어           y=2.0  플레이어 머리
  │  │  └───┘     │                   y=1.5  Air 장애물 하단
  │  │            │                   y=1.0  플레이어 허리
  ├──┤  ─────  ───┴───  ═══════════   y=0.2  인도 윗면
  ████  █████  ████████████████████   y=0    도로 윗면 / 플레이어 발
```

- 배경 오브젝트 높이는 **3.0m 이하**로 제한 (카메라 y=7에서 내려다보므로 그 이상은 장애물 시야를 가림)
- 단, 벽/천장 등 의도적 폐쇄감을 주는 오브젝트는 예외

## Stage 1: Office (사무실 복도)

### 컨셉
좁은 사무실 복도. 양쪽에 파티션과 책상이 빽빽하게 늘어서 있어 답답한 느낌.

### 화면 구성 (단면도)

```
  파티션벽│책상│     도 로 (8m)      │책상│파티션벽
  ┌─┐┌──┐│    │                    │    │┌──┐┌─┐
  │ ││모 ││    │  L-1   L0   L+1   │    ││모 ││ │
  │벽││니 ││책상│                    │책상││니 ││벽│
  │ ││터 ││    │        ☻          │    ││터 ││ │
  │ ││  ││    │        │          │    ││  ││ │
  └─┘└──┘│    │                    │    │└──┘└─┘
  ████████████████████████████████████████████████
  x=-10  -7   -4                  +4   +7   +10
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **파티션 벽** | Cube | 0.3 × 2.5 × 4 | x=±8, y=1.25 | 5m 간격, 좌우 대칭 | 밝은 베이지 |
| **책상** | Cube | 1.5 × 0.75 × 1.0 | x=±5.5, y=0.58 (인도 위) | 파티션 사이마다 1개 | 연한 갈색 |
| **모니터** | Cube | 0.6 × 0.4 × 0.05 | 책상 위, y=1.18 | 책상마다 1개 | 검정 |
| **의자** | Cube | 0.5 × 0.8 × 0.5 | 책상 옆, x=±4.5 | 책상마다 1개 | 어두운 회색 |
| **형광등** | Cube (얇은) | 1.0 × 0.05 × 0.1 | y=2.8, x=0 | 10m 간격, 도로 위 | 밝은 흰색 (Emission) |
| **천장 프레임** | Cube | 14 × 0.1 × 0.3 | y=3.0, x=0 | 10m 간격, 횡방향 | 밝은 회색 |

### 바닥
- Road: M_Road → **M_OfficeFloor** (밝은 베이지/크림색)으로 교체
- Sidewalk: 동일 색상 (사무실이라 도로/인도 구분 없음, 연속 바닥 느낌)
- LaneLine: 유지 (레인 가이드 필요)
- Curb/EdgeLine: 숨기거나 색상 통일 (사무실에 연석은 어색)

### 카메라에서 보이는 화면

```
  ┌─────────────────────────────────────┐
  │           [형광등]                   │
  │  ┌벽┐ ┌책상┐              ┌책상┐ ┌벽┐│
  │  │  │ │모니│              │모니│ │  ││
  │  │  │ │터 │     ☻        │터 │ │  ││
  │  │  │ └──┘    /|\        └──┘ │  ││
  │  └──┘         / \             └──┘│
  │  ════════════════════════════════  │
  │         --- --- --- ---           │
  └─────────────────────────────────────┘
```

### 공간감 핵심
- 파티션 벽이 좌우를 막아 **좁은 복도** 느낌
- 형광등이 머리 위에 반복되며 **실내** 느낌
- 책상/모니터가 반복되며 **사무실** 인식

## Stage 2: Lobby (로비)

### 컨셉
넓고 높은 빌딩 로비. 기둥이 공간을 리드미컬하게 나누고, 바닥은 밝다.

### 화면 구성 (단면도)

```
  기둥                 도 로 (8m)                 기둥
  ┌┐                                              ┌┐
  ││    화분                            화분       ││
  ││    (●)    L-1    L0    L+1         (●)       ││
  ││                  ☻                            ││
  ││                  │                            ││
  └┘                                              └┘
  █████████████████████████████████████████████████
  x=-9       -6      -4              +4      +6   +9
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **로비 기둥** | Cylinder | r=0.4, h=3.0 | x=±9, y=1.5 | 10m 간격, 좌우 대칭 | 대리석 밝은 회색 |
| **화분** | Cylinder+Sphere | r=0.3 h=0.6 + r=0.4 | x=±6, y=0.5 (인도 위) | 15m 간격 | 갈색 화분 + 초록 구 |
| **안내 데스크** | Cube | 2.0 × 1.0 × 1.0 | x=±6, y=0.7 | 스테이지 초반에 1~2개 | 진한 갈색 |
| **보안 게이트 프레임** | Cube 2개 | 0.2 × 1.2 × 0.3 | x=±도로 양끝 | 장애물 패턴과 연동 | 스테인리스 은색 |

### 바닥
- Road: **M_LobbyFloor** (밝은 대리석 흰색)
- Sidewalk: 동일 (넓은 로비 바닥 연속)
- Curb/EdgeLine: 숨김
- LaneLine: 얇은 바닥 무늬로 대체하거나 유지

### 공간감 핵심
- Office 대비 양쪽 장식이 **멀리** 배치 → 탁 트인 넓은 공간
- 높은 기둥(3m)이 로비의 높은 천장을 암시
- 바닥이 밝아져 실내지만 Office보다 환한 느낌
- 천장 프레임 없음 → 개방감

## Stage 3-A: Commute 밤거리

### 컨셉
비 오는 밤 도심 거리. 가로등 불빛만 있고 주변은 어둡다.

### 화면 구성 (단면도)

```
  건물벽│가로등                            가로등│건물벽
  ┌───┐│  ○                                ○  │┌───┐
  │   ││  │     L-1    L0    L+1           │  ││   │
  │   ││  │                  ☻             │  ││   │
  │   ││  │                  │             │  ││   │
  └───┘│  │                                │  │└───┘
  ████████████████████████████████████████████████
  x=-11 -8 -6    -4                   +4   +6 +8  +11
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **가로등 기둥** | Cylinder | r=0.08, h=2.8 | x=±6, y=1.4 | 10m 간격 | 어두운 회색 |
| **가로등 불빛** | Sphere | r=0.2 | x=±6, y=2.9 | 기둥 위 | 노란색 (Emission) |
| **건물 벽** | Cube | 3 × 3 × 20 | x=±9.5, y=1.5 | 타일 전체 길이 | 어두운 갈색/회색 |
| **벤치** | Cube | 1.2 × 0.5 × 0.4 | x=±5, y=0.45 (인도 위) | 20m 간격 | 갈색 |
| **가판대/간판** | Cube | 0.8 × 1.5 × 0.3 | x=±8, y=0.95 | 15m 간격 | 다양한 색 |

### 바닥
- Road: **M_WetRoad** (젖은 느낌, 어두운 회색 + 약간의 반사)
- Sidewalk: **M_WetSidewalk** (젖은 보도블럭, 어두운 회색)

### 조명
- Directional Light 강도를 낮추거나 색을 어둡게
- 가로등 Sphere에 Point Light 또는 Emission 머티리얼

### 공간감 핵심
- 양쪽에 **건물 벽**(높이 3m)이 도시 느낌
- 가로등이 리듬감과 야간 분위기
- 전체적으로 어둡지만 도로와 장애물은 식별 가능

## Stage 3-B: Commute 승강장

### 컨셉
지하철 승강장. 양쪽에 벽과 스크린도어가 있는 좁은 공간.

### 화면 구성 (단면도)

```
  벽│스크린도어                        스크린도어│벽
  ┌┐┌──┬──┬──┐                       ┌──┬──┬──┐┌┐
  │││  │  │  │  L-1   L0   L+1      │  │  │  │││
  │││  │  │  │         ☻            │  │  │  │││
  │││  │  │  │         │            │  │  │  │││
  └┘└──┴──┴──┘                       └──┴──┴──┘└┘
  █████████████████████████████████████████████████
  x=-8  -6  -4                       +4  +6    +8
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **승강장 벽** | Cube | 1.0 × 3.0 × 20 | x=±7.5, y=1.5 | 타일 전체 | 타일 무늬 밝은 회색 |
| **스크린도어 프레임** | Cube | 0.15 × 2.0 × 0.3 | x=±5, y=1.0 | 2.5m 간격 | 스테인리스 은색 |
| **스크린도어 유리** | Cube (반투명) | 0.05 × 1.5 × 2.2 | x=±5, 프레임 사이 | 프레임 사이 | 연한 파랑 반투명 |
| **노란 안전선** | Cube | 0.3 × 0.01 × 20 | x=±4.2, y=0.01 | 도로 가장자리 | 노란색 |

### 바닥
- Road: **M_PlatformFloor** (밝은 회색, 타일 느낌)
- Sidewalk: 동일

### 공간감 핵심
- 벽과 스크린도어가 **밤거리보다 더 가까이** 배치 → 좁아지는 느낌
- 노란 안전선이 승강장 인식
- 밤거리에서 전환 시 갑자기 밝아지며 실내 느낌

## Stage 3-C: Commute 객실 내부

### 컨셉
만원 지하철 내부. 양쪽 벽이 바로 옆, 위에 손잡이가 반복.

### 화면 구성 (단면도)

```
  ┌──────────── 천장 ────────────┐    y=2.8
  │  손잡이  손잡이  손잡이  손잡이│    y=2.2
  │                              │
  벽  L-1    L0    L+1           벽
  │              ☻               │
  │              │               │
  └──────────────────────────────┘
  █████████████████████████████████
  x=-5                          x=+5
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **객실 벽** | Cube | 0.3 × 2.8 × 20 | x=±5, y=1.4 | 타일 전체 | 스테인리스 밝은 회색 |
| **천장** | Cube | 10.3 × 0.1 × 20 | x=0, y=2.8 | 타일 전체 | 밝은 회색 |
| **손잡이 바** | Cylinder | r=0.03, h=10 (X축 회전) | y=2.2, x=0 | 5m 간격, Z방향 | 은색 |
| **손잡이 고리** | Cylinder | r=0.05, h=0.3 | y=2.0, 바 아래 | 바에 1m 간격 매달림 | 은색 |
| **좌석** | Cube | 0.6 × 0.4 × 4 | x=±4.5, y=0.4 (벽 옆) | 벽 따라 연속 | 파란색 |
| **창문** | Cube (반투명) | 0.05 × 0.8 × 1.5 | x=±4.85, y=1.6 | 벽에 2m 간격 | 어두운 파랑 반투명 |

### 바닥
- Road: **M_TrainFloor** (연한 회색/녹색)
- Sidewalk: 숨김 또는 벽 안쪽이므로 불필요

### 공간감 핵심
- **벽 x=±5**: Office/Lobby보다 가장 좁음 → 극도의 답답함
- **천장 y=2.8**: 유일하게 천장이 완전히 덮인 구간
- 손잡이가 머리 위에 반복 → 만원 지하철 느낌
- 플레이 영역(3레인)은 동일하지만 시각적으로 압박감

## Stage 4: Home (골목 → 집)

### 컨셉
조용한 골목길에서 집 안까지. 따뜻한 조명, 장애물 없음.

### 화면 구성 - 골목 (단면도)

```
  담벼락│가로등                         가로등│담벼락
  ┌────┐│ ○                              ○ │┌────┐
  │    ││ │      L-1   L0   L+1          │ ││    │
  │    ││ │             ☻                │ ││    │
  └────┘│ │             │                │ │└────┘
  ████████████████████████████████████████████████
  x=-9  -6                                +6  +9
```

### 화면 구성 - 집 내부 (단면도)

```
  ┌──────────── 천장 ────────────┐   y=2.5
  │                              │
  벽                    [침대]   벽
  │        ☻                     │
  │        │                     │
  └──────────────────────────────┘
  █████████████████████████████████
  x=-5                          x=+5
```

### 배치 오브젝트

| 오브젝트 | 형태 | 크기 (W×H×D) | 위치 | 배치 규칙 | 머티리얼 색상 |
|---|---|---|---|---|---|
| **담벼락** | Cube | 0.5 × 2.0 × 20 | x=±8, y=1.0 | 타일 전체 | 연한 갈색/벽돌색 |
| **골목 가로등** | Cylinder+Sphere | 위와 동일 | x=±6, y=1.4 | 15m 간격 | 따뜻한 노란 Emission |

| **침대** | Cube | 2.0 × 0.5 × 2.5 | x=0, y=0.25 | 최종 트리거 위치 | 흰색/파란색 |
| **베개** | Cube | 1.5 × 0.2 × 0.4 | 침대 위, z끝 | 1개 | 흰색 |
| **TV** | Cube | 1.0 × 0.6 × 0.05 | x=±4, y=1.0 | 1개 | 검정 |

### 바닥
- 골목: **M_AlleyRoad** (어두운 아스팔트, 밤거리와 비슷하지만 조금 밝게)
- 집 내부: **M_HomeFloor** (나무 바닥색, 따뜻한 갈색)

### 조명
- 골목: 가로등 따뜻한 노란빛, 전체 조명은 어둡지만 도심보다 부드러움
- 집 내부: 따뜻한 주황/노란 조명, 밝음

### 공간감 핵심
- 속도 감소 → 여유로운 걸음
- 조명이 따뜻해지며 **안도감**
- 장애물 없음 → 순수하게 공간을 감상
- 침대가 보이면 게임 완료 느낌

## 타일 프리팹 구성 방침

배경 오브젝트를 배치하는 방법은 두 가지이며, 스테이지별로 선택한다:

### 방법 A: 타일 프리팹에 포함
- 배경 오브젝트를 GroundTile 프리팹의 자식으로 넣는다
- 타일이 재활용될 때 배경도 함께 이동한다
- 스테이지별로 다른 타일 프리팹을 사용한다
- **장점**: 구현 단순, 배치 안정적
- **단점**: 스테이지별 프리팹 관리 필요

### 방법 B: 별도 배경 스포너
- 배경 오브젝트를 별도 풀링 시스템으로 스폰한다
- GroundSpawner처럼 플레이어 위치 기반으로 전방에 생성, 후방 회수
- **장점**: 타일과 배경 독립, 유연한 배치
- **단점**: 추가 시스템 구현 필요

**권장**: 방법 A로 시작 — 스테이지별 타일 프리팹(GroundTile_Office, GroundTile_Lobby 등)을 만들고, StageManager가 전환 시 GroundSpawner의 프리팹을 교체한다.
